Les
compléments

Sujet, verbe… et plus

Une phrase a un sujet et un verbe.

Elle peut avoir des compléments.

Ce matin, Léa mange une pomme dans la cuisine.

Le complément d’objet

  • Il complète le verbe : il se place après lui.
  • On ne peut pas le déplacer.
Tom lance le ballon. → COD
Il parle à sa mère. → COI

COI : avec un petit mot (à, de) après le verbe.

Compléments circonstanciels

  • Ils donnent des précisions sur l’action.
  • On peut les supprimer et les déplacer.
Hier, Léa a joué
dans le parc joyeusement.

Les tests

1. Je supprime :

Ce matin, les élèves chantent dans la cour.

La phrase a encore du sens.

2. Je déplace :

Dans la cour, les élèves chantent.

Attention !

  • En début de phrase, le complément circonstanciel est suivi
    d’une virgule : Le matin, les oiseaux chantent.
  • Une phrase peut avoir plusieurs compléments.
  • Le test le plus sûr : je déplace.
    Le complément d’objet ne bouge pas.
