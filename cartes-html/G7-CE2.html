Grammaire — G7 — CE2
La chaîne
des accords

Dans le GN

Le déterminant et l’adjectif s’accordent avec le nom.

les petites filles

féminin → souvent e · pluriel → souvent s

Sujet → verbe

Le verbe s’accorde avec son sujet.

La fille chante.
Les filles chantent.

Le participe passé avec être

Avec être, il s’accorde avec le sujet, comme un adjectif.

Tom est parti. · Léa est partie.
Ils sont partis. · Elles sont parties.

Avec avoir : pas d’accord avec le sujet.
Léa a mangé.

La chaîne complète

Le nom du sujet commande toute la chaîne.

Les petites filles chantent.

filles → féminin pluriel

les · petites · filles · chantent : tout s’accorde !

Le petit chat dort.
→ Les petits chats dorment.

Je vérifie

  1. Je trouve le nom du sujet : masculin ou féminin ? singulier ou pluriel ?
  2. J’accorde le GN.
  3. J’accorde le verbe.
