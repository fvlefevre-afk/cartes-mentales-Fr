Deux groupes

Une phrase se découpe en deux groupes.

Le chat mange sa pâtée.

Groupe sujet + groupe verbal.

Le groupe sujet

  • Il dit de qui ou de quoi on parle.
  • Je le trouve avec « qui est-ce qui ? ».
Les oiseaux construisent un nid.
→ ils construisent un nid

Le groupe verbal

  • C’est le verbe et ce qui le complète.
  • Le verbe en est le mot le plus important.
Les oiseaux construisent un nid.

Je manipule la phrase

Je supprime : Ce matin, les élèves chantent dans la cour.

Je déplace : Dans la cour, les élèves chantent.

J’ajoute : les petits élèves chantent joyeusement.

Je remplace : Les enfants courent. → Ils courent.

Attention !

  • Le groupe sujet peut avoir plusieurs mots : Mon petit frère dort.
  • Quand je supprime ou je déplace des mots, la phrase doit garder son sens.
  • Le verbe ne se supprime jamais.
