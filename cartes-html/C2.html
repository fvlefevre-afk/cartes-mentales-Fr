Le futur
simple

Pour parler de demain

Le futur dit ce qui va se passer.

J’ajoute la terminaison à l’infinitif :

chanter + ai → je chanterai

Toujours un r avant la terminaison : c’est la marque du futur.

Les terminaisons

il, ellechantera

vouschanterez
ils, elleschanteront

2e groupe : je finirai, nous grandirons

jouer → je jouerai : le e s’écrit, même si on ne l’entend pas.

Les verbes irréguliers

Le radical change : je l’apprends. Les terminaisons restent les mêmes.

allerj’irai
faireje ferai
direje dirai
venirje viendrai
pouvoirje pourrai
voirje verrai
vouloirje voudrai
prendreje prendrai

Attention !

  • Toujours un r avant la terminaison.
  • Deux r : je pourrai, je verrai.
  • Verbes en -re : j’enlève le e : prendre → je prendrai.
