Le passé
composéavec être

être + participe passé

Certains verbes font leur passé composé avec l’auxiliaire être.

Hier, je suis parti.
Tom est arrivé.

Les verbes avec être

Surtout des verbes de mouvement :

aller · venir · partir · arriver
entrer · sortir · monter · descendre
tomber · rester · naître

J’accorde avec le sujet

Avec être, le participe passé s’accorde avec le sujet.

Tom est parti.
Léa est partie.
Ils sont partis.
Elles sont parties.

être au présent

jesuis
tues
il, elleest
noussommes
vousêtes
ils, ellessont

Le verbe être est ici l’auxiliaire.

Attention !

  • Avec être : j’accorde. Avec avoir : je n’accorde pas avec le sujet.
    Elle est tombée. · Elle a joué.
  • Les verbes avec se se conjuguent aussi avec être : il s’est levé, elle s’est levée.
