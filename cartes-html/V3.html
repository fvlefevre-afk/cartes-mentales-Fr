Un mot en morceaux

Un mot peut être fait d’un mot de base et de morceaux ajoutés.

refaire → faire à nouveau
jardinier → un métier

Devant : un préfixe. Derrière : un suffixe.

Les préfixes

re-à nouveau : relire
dé-le contraire : décoller
in- im-pas : inconnu, impossible
mal-pas : malheureux

Les suffixes

-ierun métier : jardinier
-eur, -eusequi fait : chanteur
-ettepetit : fillette
-ablequ’on peut : lavable
-mentde quelle manière : doucement

Je comprends un mot

Les morceaux sont des indices dans le mot.

Ce vase est incassable.
→ qu’on ne peut pas casser
Ce jouet est démontable.
→ qu’on peut démonter

Attention !

  • Il faut un mot de base qui existe : reine n’est pas re + ine.
  • On écrit im- devant b, p et m : impossible, imbuvable.
  • Un même mot peut avoir un préfixe et un suffixe : incassable.
