Comprendre
un mot inconnuavec les indices

Les indices dans la phrase

Je lis toute la phrase : les autres mots m’aident.

Le boulanger sort le pain du fournil encore brûlant.
→ le fournil : la pièce où l’on cuit le pain.

Les indices dans le mot

Je cherche un mot que je connais, caché dans le mot.

incassable → qu’on ne peut pas casser
chocolatier → une personne qui fabrique du chocolat

Ma méthode

  1. Je lis toute la phrase.
  2. Je cherche des indices dans la phrase et dans le mot.
  3. Je propose un sens.
  4. Je vérifie : je remplace le mot par mon explication ; la phrase doit garder son sens.
Le chat lape son lait. → Le chat boit son lait en tirant la langue.

Attention !

Parfois, la phrase ne suffit pas :

Le tamanoir est un animal.
→ je sais seulement que c’est un animal.

Je lis alors la suite du texte, ou je demande.
