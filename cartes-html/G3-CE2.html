Grammaire — G3 — CE2
Le groupe
nominalle GN

Le GN, c’est…

  • un groupe de mots organisé autour d’un nom.
  • déterminant + nom (+ adjectif)
le petit chat noir

Déterminants : le, la, les, un, une, des, mon, ce…

Le nom

  • C’est le mot le plus important du GN. Je l’entoure.
  • On ne peut pas l’enlever.
une grande maison blanche
→ une maison

L’adjectif

  • Il dit comment est le nom.
  • Il se place avant ou après le nom.
un gros ballon rouge
une souris → une petite souris grise

Les accords dans le GN

Le nom commande : le déterminant et l’adjectif s’accordent avec lui.

Masculin → féminin

J’ajoute souvent un e.
un ami content
  → une amie contente
Parfois, le mot change :
  joyeux → joyeuse · lecteur → lectrice

Singulier → pluriel

J’ajoute souvent un s.
le chat noir
  → les chats noirs
une fleur jaune
  → des fleurs jaunes

Attention !

  • Pluriel en x : des gâteaux, des jeux.
  • -al → -aux : un cheval, des chevaux.
  • Déjà -s, -x, -z : pas de changement.
    une souris → des souris
  • Déjà -e au masculin : pas de changement.
    un vélo rouge → une moto rouge
