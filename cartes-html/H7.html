Homophones — H7 — CM1
se, s’esthomophones

se : devant un verbe

se pronom, devant un verbeJe prouve : je change la personne : je meIl se lave.
→ Je me lave.
Les chats se cachent.

je me, tu te, il se

Le pronom change avec la personne :

je me lave · tu te laves
il, elle se lave
nous nous lavons · vous vous lavez
ils, elles se lavent

s’est : au passé composé

s’est se + est : le passé composéJe prouve : je change la personne : je me suisTom s’est levé.
→ Je me suis levé.

Il se lève (aujourd’hui) → il s’est levé (hier).

L’accord avec s’est

Comme avec être, le participe passé s’accorde avec le sujet.

Tom s’est levé.
Léa s’est levée.
Ils se sont levés.

Attention !

  • se est suivi d’un verbe conjugué : il se cache.
  • s’est est suivi d’un participe passé : il s’est caché.
  • Au pluriel, s’est devient se sont : ils se sont cachés.
