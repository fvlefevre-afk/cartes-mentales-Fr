# En CM2

Les deux régimes d’écrit (écrits de travail, écrits longs) restent les mêmes. Le programme 2025 (CM2) précise :

| Programme CM2 | Où dans ce dispositif |
|---|---|
| Écrire pour comparer deux documents ; écrits réflexifs courts pour expliquer un point de vue intégrant plusieurs documents | Écrits de travail (§2.1), en histoire, géographie, sciences, EMC |
| Reformuler l’essentiel d’une leçon, y compris de manière schématique | Écrits de travail ; trace écrite en carte mentale |
| Décrire, dialoguer ; nuancer un avis, imaginer une suite avec dialogue ou description | Écrits longs (Dispositif 7a) et écrits courts (Dispositif 7b) |
| Autonomie dans le respect des codes de l’écrit ; cohérence textuelle ; brouillon ; amélioration du texte | Écrits longs (Dispositif 7a, démarche en dix étapes) |

La norme attendue reste ciblée sur les ceintures déjà validées par l’élève : pour un CM2, ce sont les ceintures CM2 (avec leur ajout).
