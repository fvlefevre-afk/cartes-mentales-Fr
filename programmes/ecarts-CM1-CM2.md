# Du CM1 au CM2 : ce qui change

Comparaison faite le 17 octobre 2026 entre :
- les leçons CM1 du site ;
- le programme de français du cycle 3, partie « Cours moyen deuxième année » (`programme-francais-cycle-3.pdf`) ;
- le parcours C (CM2) des cahiers de progrès CE2-CM1-CM2.

Pour l'instant, chaque leçon CM2 du site est une **copie** de la leçon CM1 qui porte le même numéro.

Légende de la colonne « Que faire » :
- **garder** : la copie CM1 convient presque telle quelle ;
- **compléter** : ajouter des écrans ;
- **nouvelle leçon** : la notion n'existe pas en CM1.

## Grammaire (parcours C : 7 ceintures)

| CM2 | Cahier de progrès CM2 | Leçon CM1 copiée | Que faire |
|---|---|---|---|
| G1 | Phrase sujet + verbe, y compris le sujet inversé | G1 Qu'est-ce qu'une phrase ? | compléter : plus de sujets après le verbe (« Dans la forêt vivent des loups », questions) |
| G2 | Phrase simple et phrase complexe (je compte les verbes conjugués) | G2 Types et formes de phrase | nouvelle leçon (les types et formes restent en révision, avec des phrases plus longues) |
| G3 | Chaîne d'accords étendue, complément du nom, épithète ou attribut | G3 Le groupe nominal | compléter : complément du nom (« un pull **en laine** »), épithète / attribut |
| G4 | Classes de mots + préposition ; pronom complément ou déterminant (le, la, les) | G4 Les classes de mots | compléter : prépositions, « le/la/les » devant un nom ou devant un verbe ; nature et fonction |
| G5 | Accord sujet-verbe, y compris le sujet inversé | G5 L'accord sujet-verbe | compléter : sujet inversé ; accord avec l'attribut (« Les filles sont contentes ») |
| G6 | COD et COI distingués, préposition du COI ; compléments circonstanciels de temps, de lieu, de cause | G6 Les compléments | à refaire en grande partie : COD / COI, compléments circonstanciels classés, attribut du sujet ou complément d'objet |
| G7 | Chaîne d'accords étendue : GN + sujet-verbe + attribut + participe passé avec être | G7 La chaîne des accords | compléter : l'attribut du sujet |

Le programme CM2 demande aussi, sans ceinture prévue dans le cahier :
- **les conjonctions de subordination**, en lien avec la phrase complexe (G2 ou G4) ;
- **les pronoms compléments et leurs variations** (G4).

## Conjugaison (parcours C : 5 ceintures)

Attention : les numéros ne correspondent plus. Le C2 du CM2 n'est pas le futur, etc.

| CM2 | Cahier de progrès CM2 | Leçon CM1 copiée | Que faire |
|---|---|---|---|
| C1 | Révision : présent, imparfait, futur, passé composé | C1 Le présent | nouvelle leçon de révision (proche de C8 « Mobilisation » du CM1) |
| C2 | Accord du participe passé avec être ; accord avec le sujet inversé | C2 Le futur | nouvelle leçon (reprend une partie de C5 du CM1) |
| C3 | Plus-que-parfait (à partir du passé composé) | C3 L'imparfait | nouvelle leçon |
| C4 | Passé simple : être, avoir, 1er groupe | C4 Le passé composé avec avoir | nouvelle leçon |
| C5 | Passé simple : 2e groupe et verbes irréguliers | C5 Le passé composé avec être | nouvelle leçon |
| (C8) | — pas dans le cahier CM2 | C8 Mobilisation | à retirer, ou à garder comme transfert ? |

Le programme CM2 demande aussi, sans ceinture prévue dans le cahier :
- l'accord du participe passé avec le COD (auxiliaire avoir, verbes étudiés) ;
- la forme négative aux temps composés ;
- les radicaux qui changent (1er et 3e groupes).

## Homophones (parcours C : 8 ceintures)

| CM2 | Cahier de progrès CM2 | Leçon CM1 copiée | Que faire |
|---|---|---|---|
| H1 | avoir / être conjugués | H1 | garder (avec plus de temps et de personnes) |
| H2 | on, là, où | H2 | garder |
| H3 | ce, ces, à, **sans** | H3 | compléter : sans |
| H4 | et, ou, mais, **donc** | H4 | compléter : donc |
| H5 | la, c'est | H5 | garder |
| H6 | son, ses, mes, **quel(s), quelle(s)** | H6 | compléter : quel, quelle |
| H7 | se, s'est, **s'en** | H7 | compléter : s'en |
| H9 | dont, qu'elle(s) | H8 Transfert | nouvelle leçon (H8 n'est pas dans le cahier CM2) |

Règle des jumeaux vérifiée : chaque mot ajouté et son jumeau restent dans des ceintures différentes.
- sans (H3) / s'en (H7) ;
- donc (H4) / dont (H9) ;
- quel (H6) / qu'elle (H9).

## Orthographe

Il n'existe pas de cahier de progrès CM2 pour l'orthographe. Le programme CM2 garde le même objectif qu'en CM1 :
écrire correctement les mots fréquents grâce aux régularités et à la formation des mots.
Les ceintures O1 à O6 peuvent rester telles quelles, en révision.

## Couleurs des ceintures

Le cahier CM2 utilise : blanche, jaune, orange, verte, bleue, rouge, violette, marron (sans rose).
Le CM1 du site utilise : blanche, rose, jaune, orange, verte, bleue, violette, marron.
